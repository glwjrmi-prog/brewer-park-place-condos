After each meeting

  1. Save the finished, approved minutes as a PDF. Use the clean formatting used for the existing minutes. In Word, choose File → Save As → PDF. In Google Docs, choose File → Download → PDF Document.
  2. Name the PDF with the meeting date. Use the helper below, for example 2026-10-15 - Board Meeting Minutes.pdf. Use the date the meeting took place.
  3. Upload and save it. Click Upload Finished Minutes below. On GitHub, click choose your files and select the named PDF. Leave Commit directly to the main branch selected, then click Commit changes at the bottom.

The website adds the link under the correct year automatically. Allow up to 10 minutes, then refresh Board Meeting Minutes to check it.

The PDF keeps the formatting of the document you provide. Uploading does not edit or reformat the minutes.

Keep these instructions handy

Bookmark this page. You can also open it from Upload Meeting Minutes in the website footer.

Use the same upload button for every meeting and every year. You do not need to edit the website or ask Codex to add each new link.

If something needs correcting

The new link is missing: wait up to 10 minutes, refresh the website, and check that the file is a PDF named with a valid meeting date. Click View Uploaded Files to confirm that GitHub saved it in the minutes folder.

Replace a PDF: upload the corrected PDF with the exact same file name, then click Commit changes. The existing link will open the corrected version after the website publishes.

Wrong date or file name: save a correctly named PDF and upload it. In View Uploaded Files, open the incorrectly named file, choose Delete file from its menu, and commit that deletion.

Browser uploads must be smaller than 25 MiB. Deleted or replaced files can still have earlier versions in GitHub's history.
