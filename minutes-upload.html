After each meeting

  1. Use the finished, approved minutes. Keep the clean formatting used for the existing minutes. A PDF preserves the appearance when residents open or print it. Google Docs are also supported.
  2. Name the file with the meeting date. Use the helper below, for example 2026-10-15 - Board Meeting Minutes.pdf. A Google Doc uses the same name without .pdf.
  3. Put the file in its year folder. Open the folder below. Upload a PDF with New → File upload, or drag it into the Drive folder. A finished Google Doc can be moved into the same folder.

Once the connection is active, the website adds the link under the correct year. Allow about a minute, then refresh the website.

Use this folder only for minutes ready to be viewed on the website. It is not a drafts folder. Uploading preserves the document you provide; it does not reformat its contents.

For a new year, create a folder named with its four-digit year inside BPP Approved Board Minutes. The website will recognize it automatically.

The existing meeting-minute links remain available. Only new minutes need to use this upload folder.

One-time Google connection

This setup is needed once. After it is connected, use the three meeting steps above.

  1. Open BPP Approved Board Minutes. Choose Share → General access → Anyone with the link → Viewer, then save. This sets viewing access for finished minutes placed here.
  2. Open Google Apps Script using building@bppcondos.org. Click New project and name it BPP Minutes Publisher.
  3. In Code.gs, replace the starter code with the script below. Use Copy Script to copy it, then save.
  4. Open Project Settings, enable Show “appsscript.json” manifest file in editor, and return to the editor. Replace appsscript.json with the manifest below and save. It requests read-only Drive access.
  5. Choose Deploy → New deployment → Web app. Set Execute as to Me and Who has access to Anyone. Click Deploy and complete Google's authorization for your account.
  6. Copy the Web app URL ending in /exec. Test it below, then send that URL to Codex once to finish the website connection.

The script reads this dedicated folder and its year folders. It lists publicly readable PDFs and Google Docs with a valid meeting-date file name. It does not change documents, sharing, or other Drive folders.
